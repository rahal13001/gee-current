# GLORYS12V1 Current Research & Teaching System

Repository ini menyiapkan sistem pendidikan dan penelitian nonkomersial untuk arus GLORYS12V1.
Tahap aktif saat ini adalah Epic FND, Milestone M0 (Repository Ready).

Sumber kebenaran dan batas keamanan ada di `docs/`. Belum ada pipeline data, dependency runtime,
autentikasi, asset Earth Engine, atau data GLORYS12V1 nyata di repository ini.

Pemeriksaan Foundation offline:

```powershell
.\tools\run_foundation_checks.ps1
```

Perintah tersebut tidak melakukan network, autentikasi, instalasi, download, atau upload.
