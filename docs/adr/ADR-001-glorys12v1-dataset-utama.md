# ADR-001 — GLORYS12V1 sebagai Dataset Utama

- Status: `PROPOSED` (diwarisi dari PRD; belum menjadi approval baru)
- Context: Sistem membutuhkan sumber arus utama yang konsisten.
- Decision: GLORYS12V1 tetap dataset utama.
- Alternatives: dataset lain hanya sebagai pembanding/validasi/demo berlabel.
- Scientific impact: identitas dan provenance tetap konsisten.
- Technical impact: pipeline mengikuti Product ID dan Dataset ID yang ditetapkan.
- Security/cost impact: tidak menambah layanan atau akses baru.
- Validation required: verifikasi metadata aktif pada Tahap 0 dengan approval network.
