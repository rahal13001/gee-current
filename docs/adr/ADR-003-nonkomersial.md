# ADR-003 — Pendidikan dan Penelitian Nonkomersial

- Status: `PROPOSED` (diwarisi dari PRD)
- Context: Proyek ditujukan untuk pembelajaran dan penelitian.
- Decision: Sistem bukan operasional, navigasi, keselamatan, desain teknik, atau komersial.
- Alternatives: penggunaan operasional memerlukan peninjauan kebijakan dan PRD baru.
- Scientific impact: disclaimer dan batas interpretasi wajib.
- Technical impact: tier nonkomersial dan guardrail tetap dipakai.
- Security/cost impact: layanan berbayar tidak diaktifkan tanpa approval.
- Validation required: governance review pada setiap release.
