# ADR-005 — Bulanan Penuh dan Harian JFM

- Status: `PROPOSED` (diwarisi dari PRD)
- Context: Produk inti perlu cakupan tahunan dan detail JFM.
- Decision: 132 timestep bulanan plus 993 timestep harian Januari–Maret.
- Alternatives: daily full ditunda.
- Scientific impact: periode dan jumlah timestep eksplisit.
- Technical impact: download plan dipisah monthly dan daily JFM.
- Security/cost impact: volume dibatasi untuk nonkomersial.
- Validation required: penghitungan kalender dan inventory.
