# ADR-010 — Tidak Ada Penggunaan Operasional

- Status: `PROPOSED` (diwarisi dari PRD)
- Context: GLORYS12V1 adalah reanalisis model dengan keterbatasan resolusi dan pasut.
- Decision: sistem tidak digunakan untuk operasional, navigasi, keselamatan, desain teknik, atau keputusan komersial.
- Alternatives: perubahan tujuan memerlukan PRD dan governance review baru.
- Scientific impact: disclaimer dan limitations wajib tampil.
- Technical impact: tidak ada SLA atau backend operasional.
- Security/cost impact: tidak ada service account/backend unattended pada Tahap 0–8.
- Validation required: audit governance sebelum release.
